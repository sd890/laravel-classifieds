# Laravel Classifieds

A classified ads platform built with Laravel and Livewire.

This project is a full-stack web application inspired by online classifieds platforms. 
It allows users to create, manage, search, and interact with classified listings.

## Features

### User Features

- User registration and authentication
- User profiles
- Create, edit, and delete listings
- View listing details
- Favorite listings
- Messaging between users
- Email notifications
- User dashboard

### Admin Features

- Admin dashboard
- Manage users
- Manage listings
- Manage application data

## Tech Stack

- PHP
- Laravel
- Livewire
- MySQL
- Blade
- Tailwind CSS
- JavaScript
- Git & GitHub

## Backend

The application backend is built with Laravel and includes:

- MVC architecture
- Eloquent ORM
- Database relationships
- Form validation
- Authentication and authorization
- RESTful concepts
- CRUD operations
- Policies and permissions
- Database migrations and seeders
